# Lab 12：Sequential-Access Files

依據 2021 講義與提供的原始程式完成。請從本目錄執行，方便使用題目指定的檔案：

```sh
g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic lab12_1.cpp -o lab12_1
```

其他題依序改成 `lab12_2`、`lab12_3`、`lab12_4`。每個 `.cpp` 可單獨編譯、提交。Windows 執行 `.exe`；Linux/macOS 使用 `./lab12_1`。

| 題目 | 使用方式與檔案格式 | 修正 |
| --- | --- | --- |
| 12.1 | 輸入成績檔名。檔案每筆一個 0–100 整數；輸出總人數與未滿 60 分人數 | 使用 `while (infile >> score)`，避免 EOF 重算最後一位、空檔案讀取未初始化值。不使用 `cerr` 或 `exit(1)`。 |
| 12.2 | 輸入禮物檔名，再選禮物編號。首行 `No. Present`，後續每行編號和至多 20 字元的英數禮物名，至多 50 件 | 修正檔案重開 failbit、零號越界、假 EOF 禮物和錯誤編號。以實際編號查找，輸出 `原檔名out.txt`。 |
| 12.3 | 選單 7 載入會員檔。首行 `Name Password`，後續每行帳號與密碼 | 正確逐行追加會員，不把標題與 EOF 當會員。修正跨帳號驗證與全域索引。5 登入或登出、6 名單、8 離開。 |
| 12.4 | 啟動時固定讀取本目錄 `4_1.txt`，持續輸入欲查單字，`-1` 結束 | 使用指定的 `infile.open("4_1.txt", ios::in)`。修正未檢查檔案、四方向越界、只探索第一個分支而漏解。 |

本目錄的 `1_1.txt`、`2_1.txt` 依講義例子製作；`3_1.txt` 是虛構測試帳號，沒有真實學生資料。`4_1.txt` 保留題目提供的 9×9 字母盤。

12.2 讀不到檔案時重新要求檔名；不存在的禮物編號與非數字輸入會要求重輸入。選擇 `2_1.txt` 的 5 號禮物會產生 `2_1out.txt`，內容為 `Congratulations! Your Christmas present is sneakers`。產出檔不是 repo 的必要輸入資料，不應提交。

12.3 延續最多 15 位會員與帳號密碼各 50 字元；載入資料超出容量時不會部分寫入。依講義假設，載入帳號與既有帳號不重複，且只載入一個檔案。會員資料僅存在記憶體。

12.4 支援上下左右任意轉彎，大小寫相符才算命中。採用回溯搜尋，每一次單字路徑不重用同一格；這項通常的 word-search 規則在講義文字沒有明說，因此在此列明。文字盤必須是 81 個字母，可以有空白與換行。例如 `HELLO`、`COMPUTER`、`LLVOIRP` 輸出 `True`，`ZZZZZ` 輸出 `False`。

repo 根目錄執行 `python tests/test_labs_10_14.py`。測試在暫存工作目錄放置檔案，檢查 EOF、空檔、遺失檔案、禮物輸出內容、會員追加/登入/登出，以及字母盤邊界與多分支回溯。
