# Lab 11：Pointer (II)

依據 2021 講義與提供的原始程式完成。四個 `.cpp` 皆可單獨編譯及提交：

```sh
g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic lab11_1.cpp -o lab11_1
```

其他題依序改成 `lab11_2`、`lab11_3`、`lab11_4`。Windows 執行 `.exe`；Linux/macOS 使用 `./lab11_1`。

| 題目 | 輸入與功能 | 題目限制與修正 |
| --- | --- | --- |
| 11.1 | 一行最多 20 個 `int`；最大、最小、次大、次小交錯排序 | 選擇排序實際使用 `void wave_sort(int *, const int, bool(*)(int,int), bool(*)(int,int))`。修正奇數長度越界並保留函式指標概念。 |
| 11.2 | 先輸入兩矩陣的列數與行數，再逐列輸入兩矩陣；輸出乘積 | 每個維度 1–10，元素 signed 64-bit。全程以指標存取，程式沒有 `[]`。修正錯誤的可乘條件、從 1 開始的越界與 32-bit 乘積溢位。 |
| 11.3 | 劇院系統：1–4 座位、5 會員中心、6 會員名單、7 離開；登入後 8 登出 | 使用 `void show_member(...)`；按照建立順序列出帳號，無會員顯示 `No Member`。修正跨帳號驗證、名單空項、輸入失敗無限循環及越界。 |
| 11.4 | 一個 4–50000 整數；計算兩質數相加的不同組數 | 埃拉托斯特尼篩法，僅檢查至 `n/2`，避免重複計算 `a+b` / `b+a`。移除逐組反覆試除造成的慢速實作。 |

11.2 可乘條件是第一矩陣的行數等於第二矩陣的列數，即 `columns1 == rows2`。不符合時輸出 `Cannot multiply these two matrixes.` 並結束。10 個 signed 64-bit 乘積的總和可能超過 128 bits，所以使用簡單的十進位分塊整數，支援精確乘法與正負加總；不依賴非標準 `__int128` 或外部函式庫。

11.3 延續 10.3 的最多 15 位會員及帳號密碼 50 字元限制，保持功能之間一個空白行。登入錯誤依講義範例畫面採用 `The username and the password don't match.`。

11.4 的篩法時間複雜度為 `O(n log log n)`；作業指定的 10 ms 執行時間仍依評測機與編譯設定而定。

repo 根目錄可執行 `python tests/test_labs_10_14.py`。測試包括函式指標排序、矩陣形狀、10×10 邊界、signed 64-bit 極值的精確乘法與消去、質數試除參考答案、會員名單及座位流程。
