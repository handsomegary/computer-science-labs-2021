# Lab 8：陣列

依據課程 2021 年 Lab 8 講義與 Review，參考提供的原始程式資料夾中的 Lab 8.1–8.4 原始碼。題目要求的成績陣列、等差數列陣列、Pascal 二維陣列與飲料價目陣列皆實際使用。

每題是獨立 C++11 程式，從 repo 根目錄編譯，例如：

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic lab08/lab8_1.cpp -o lab8_1
./lab8_1
```

Windows 執行 `lab8_1.exe`；更換檔名執行其他題。

| 程式 | 使用方式 | 主要修正 |
| --- | --- | --- |
| `lab8_1.cpp` | 三個 0–100 整數成績；平均三位小數，列出依輸入順序低於 60 分者 | 直接由成績陣列計算平均，修正原版先用三個獨立變數計算、事後才放入陣列的不符規格問題。 |
| `lab8_2.cpp` | 輸入首項、公差、正項數；負項及負總和加括號 | 動態陣列取代固定 100 格陣列，修正大於 100 項的越界。單項用 64 位元整數；總和以先除二的等差公式、十進位字串乘法輸出，避免總和溢位。項數至少為 1；依講義字面容許首項與公差 -2³¹−1 至 2³¹−1。 |
| `lab8_3.cpp` | 反覆輸入 1–30，印對應 Pascal 三角形；0 結束 | 使用初始化的 `int[30][30]`，第 30 列仍在整數範圍內；修正非法維度、EOF 與無效輸入。 |
| `lab8_4.cpp` | 依序輸入飲料種類與口味；0 結束並輸出總價 | 完整價目表取自 2021 Review。修正非法索引越界，冷飲／咖啡各 8 種、熱飲 4 種；種類或口味為 0 都結束，符合原始程式行為。 |

Lab 8.4 講義文字要求列出已買品項及價格，但講義與 Review 範例只印 `-----Menu-----` 與 `Total Cost`。預設遵循範例格式，例如輸入 `1 2 3 2 0` 得到總價 140；加上 `--receipt` 可顯示每個已買品項、數量、小計：

```sh
./lab8_4 --receipt
```

8.2 需要 O(n) 記憶體並輸出 n 項；講義允許的極大項數受實體記憶體與輸出時間限制，配置失敗會回報錯誤，不會假裝完成。各題都可由 `python tests/test_labs_6_9.py` 驗證，涵蓋及格邊界、負等差數列、101 項、Pascal 30 列、各飲料類別與非法選擇。
