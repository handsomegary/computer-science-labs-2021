# 2021 Lab 2：變數與運算

根據 2021 Lab 2 講義（P110003–P110005）與提供的原始作業修訂。保留講義的英文提示文字與預設六位有效數字輸出，每支程式獨立編譯。

| 檔案 | 輸入 | 結果與限制 |
| --- | --- | --- |
| `lab2_1.cpp` | 一個攝氏溫度實數 | 以 `C × 9.0 / 5.0 + 32` 轉為華氏，支援負溫度。 |
| `lab2_2.cpp` | 兩個整數及選項 | 選項 1 加總、2 相乘、3 較大值、4 較小值；兩個輸入採 32 位 `int`，運算結果採 `long long`。 |
| `lab2_3.cpp` | 體重（公斤）、身高（公尺） | 計算 BMI；小於 18.5、18.5 到未滿 24、24 以上分別輸出講義規定訊息。 |

例如在此目錄編譯 Lab 2.1：

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic lab2_1.cpp -o lab2_1
./lab2_1
```

其餘題目替換檔名即可。Windows PowerShell 執行 `./lab2_1.exe`。輸入 `25.5`，華氏結果為 `77.9`；Lab 2.2 輸入 `8 7 2`，相乘結果為 `56`；Lab 2.3 輸入 `74.1 1.706`，BMI 顯示 `25.4601`。

修正原作使用 `float` 的精度問題、整數相乘／加總溢位風險、未使用變數、不一致換行及錯誤輸入導致不可靠結果的情況。BMI 拒絕零或負身高、零或負體重，避免除零；不合法輸入會在標準錯誤輸出說明並以非零狀態結束。講義沒有要求這三題重新輸入，因此有效輸入的對話不增加額外訊息。

測試包括講義範例、負溫度、四種運算、32 位整數邊界、BMI 的 18.5／24 分界與零身高。
