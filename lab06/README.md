# Lab 6：函式

依據課程 2021 年 Lab 6 講義、Review 與提供的範本，參考提供的原始程式資料夾中的 Lab 6.1–6.3 原始碼修正。保留題目要求的英文提示與函式；未收錄講義 PDF 或原始資料夾副本。

每個 `.cpp` 是獨立程式，使用 C++11：

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic lab06/lab6_1.cpp -o lab6_1
./lab6_1
```

在 Windows 執行 `lab6_1.exe`；換成其他檔名可編譯各題。

| 程式 | 輸入／行為 | 修正與限制 |
| --- | --- | --- |
| `lab6_1.cpp` | 輸入三個整數，算三個階乘的最大公因數 | 保留範本的 `gcd`、`fact`、分支與迴圈；修正宣告、餘數、初值及 `cin` 名稱遮蔽。改用 64 位元無號整數，避免原版 13! 起發生帶符號溢位；超出 1–20 明確回報錯誤。 |
| `lab6_2.cpp` | 輸入三個正整數；無法構成三角形就印 `error` 並重輸入 | 使用指定的四個 `void` 函式。矩形與三角形周長、面積依原順序輸出；Heron 公式採 `long double`，面積四捨五入。修正恰好半數時的捨入、大數相加／相乘溢位及 EOF 無窮迴圈。 |
| `lab6_3.cpp` | 輸入樣本數 1–2³²−1，隨機產生 1–100 分 | 使用 `time(0)` 播種，修正原版可能產生 0 分與未播種問題。A／B／C／D／F 對應 90／80／70／60 分界；Welford 演算法計算母體標準差，平均與標準差固定小數二位。時間 O(n)、額外空間 O(1)。 |
| `lab6_1_big.cpp` | 選用擴充：三個 1–10000 整數，印出完整階乘及 GCD | 自行使用十進位字串乘法，利用 `gcd(a!,b!,c!) = min(a,b,c)!`。這個檔案是實用擴充，**不是範本除錯題的繳交替代品**。 |

Lab 6.1 的講義宣告輸入可達 2³¹−1，但其固定整數範本無法表示這些階乘；完整輸出本身也可能長達數十億位。標準解保留除錯題結構並對 64 位元溢位防呆，選用檔則明確限制實際運算量，兩者都不會把溢位值誤當答案。Lab 6.2 的範例畫面把三角形周長誤標成 rectangle，此處採用正確的 `Perimeter of the triangle` 標籤。
