# Lab 14：Class

依據 2021 課程的 Lab 14 講義（課堂日期 2022/01/06），以提供的原始程式為基礎修訂。每題為獨立、可單檔編譯的 C++11 程式。

## 14.1 四則運算

`lab14_1.cpp` 保留 `string` 儲存輸入，依照 `* / %` 高於 `+ -`、同級由左至右計算。輸入不含空白、括號或負數字面值，每個整數介於 0 與 2147483647，最後結果介於 -2147483648 與 2147483647。

原版把已計算的數設為 0 再跳過 0，會把真正的 0 運算元及減法符號處理錯誤；也有固定 100 個元素限制與整數乘法溢位。修正版分開計算乘除餘數項與加減總和，用十進位大數保存中間值，因此即使中間乘積超過 64 位元，只要最後結果符合題目範圍，仍可正確計算。除以 0、缺少運算元、非法字元、字面值或最後結果超出範圍時印出 `error` 並回傳非零狀態。

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic lab14_1.cpp -o lab14_1
./lab14_1
```

講義的三個範例：`1+2+3+4+5+6/2` 得 18、`1*2*3*4*5*6%2` 得 0、`1+2+3+4+5+6%5` 得 16。

## 14.2 計算並遮罩數字

`lab14_2.cpp` 使用指定的 `struct example { string str1; string str2; };`。`getline` 保留空白，`str1` 保存原文，`str2` 保存將 ASCII 數字替換成 `*` 的結果。原程式缺少必要的結構，也沒有實際儲存 `str2`，已補正。

## 14.3 劇院會員搜尋

`lab14_3.cpp` 延續 Lab 13.3，加入會員名稱的完整或部分字串搜尋。比對區分大小寫，依會員建立順序顯示姓名、密碼、電話；找不到時印出 `We cannot find the keyword`，再回到主選單。會員資料為本次程式的記憶體狀態，修改後不自動寫回檔案，符合題目的互動流程。

選單 1–4 為訂位、取消、可用座位、全部座位；5 為會員中心或登入後登出；6 為會員清單；7 為載入檔案；8 為修改密碼或電話；9 為搜尋；10 為離開。座位及會員上限均為 15，訂位不要求登入。

請以 `lab14` 為執行工作目錄，載入隨附的 `3_1.txt` 範例（全部為虛構測試資料），其格式為 `Name Password Phone` 表頭，後續每列三個欄位；電話以字串保存前導 0。姓名、密碼最多 50 字元，電話依題目不額外限制格式。

修正原程式使用錯誤會員索引和跨帳號密碼判斷的問題，登入與資料修改都必須以同一筆帳號資料核對姓名、密碼。訂位、會員容量、錯誤輸入和 EOF 均有處理；功能與測試詳見 `tests/test_labs_10_14.py`。

## 14.4 反轉字串

`lab14_4.cpp` 補齊題目指定的 `reverse_str` class、私有 `str0` 和三個公開函式 `set_string`、`print_string`、`reverse_string`。以兩端交換字元的方式反轉，不使用被禁止的 `std::reverse`。空字串、單字元、奇偶長度及空白皆可處理；此處依課程要求反轉 `std::string` 字元，輸入範圍為講義的英文字母、數字、空白與符號。

## 驗證

在 repo 根目錄執行 `python tests/test_lab14.py --cxx g++`。涵蓋講義範例、0 的加減乘除、負結果、同級左結合、整數上下限、大數中間值相消、超過 100 個運算元、150 組固定種子隨機運算及空字串反轉。14.3 的會員搜尋包含在 `tests/test_labs_10_14.py`。
