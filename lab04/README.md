# 2021 Lab 4：重複控制與日期

根據 2021 Lab 4 原講義、Review 與提供的原始作業修訂。保留講義的英文提示與防呆重新輸入行為。

| 檔案 | 題目 | 範圍與學習要求 |
| --- | --- | --- |
| `lab4_1.cpp` | 質因數分解（P110009） | 整數 2–2147483647；使用 `if` 與 `while`，因數由小到大且以 `*` 連接。 |
| `lab4_2.cpp` | 日期星期計算（P110010） | 日期數值 20210101–9223372036854775807；全部分支使用 `switch`，未使用 `if`／`else` 或蔡勒等星期公式。 |

在此目錄編譯與執行，例如：

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic lab4_1.cpp -o lab4_1
./lab4_1
```

Lab 4.2 替換檔名為 `lab4_2.cpp`。Windows 執行 `./lab4_1.exe`。輸入 `1260` 得到 `1260 = 2*2*3*3*5*7`；日期輸入 `20211014` 得到 `20211014 is Thursday.`。終端機輸入會顯示在提示後方；自動測試的管線輸入不會回顯輸入值。

質因數分解保留原作除法思路，但只檢查到剩餘數值的平方根；最大值是質數時也能快速完成。直接管理分隔符，移除原作使用退格字元消除尾端 `*` 的做法。

日期題統一每次重新驗證年月日，修正原作重試後漏掉前一種檢查、30 天月份、閏年天數與年度累加錯誤；依公曆規則，2100 不是閏年，2400 是閏年。從 2021-01-01 為星期五的基準，逐年、逐月累加天數。公曆每 400 年的 146097 天恰好是完整週數，因此先略過整個 400 年週期，再逐年計算剩下最多 399 年；此方式可處理講義允許的極大年份，不使用直接求星期的封閉公式。

沿用講義錯誤提示的原文字 `or is within the calculation range`（講義語意應為超出範圍），以維持課堂 I/O。兩題遇到文字／溢位輸入會清除讀取錯誤並重新提示；輸入結束時會正常離開，不會無限迴圈。

測試包含重複錯誤輸入、質數與平方因數、整數上界、Python 公曆交叉檢查、閏世紀、400 年週期、極大年份及 EOF。
