# Lab 10：Pointer (I)

依據 2021 講義與提供的原始程式完成四題。每個 `.cpp` 都可獨立編譯、提交，不依賴其他檔案。

```sh
g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic lab10_1.cpp -o lab10_1
```

其他題將檔名與輸出名稱改成 `lab10_2`、`lab10_3` 或 `lab10_4`。Windows 執行對應 `.exe`；Linux/macOS 執行 `./lab10_1`。

| 題目 | 輸入與功能 | 題目限制與修正 |
| --- | --- | --- |
| 10.1 | 一行最多 50 個 signed 64-bit 整數；輸出倒序 | `reverse` 呼叫 `swap(long long *const, long long *const)`，只在 `main` 輸出。移除以零作結尾、索引錯誤及未使用的假 `reverse`。 |
| 10.2 | 一行最多 50 個 signed 64-bit 整數；輸出山的數量及最長山 | 透過 `find_mountain(int *const num, int *const Length, ...)` 回傳結果，只在 `main` 輸出。修正越界、假零元素、32-bit 截斷及起訖長度錯誤。 |
| 10.3 | 互動式 15 席劇院；選項 1–4 管理座位，5 會員中心，6 離開；登入後 7 登出 | 使用 `void Member(...)`。最多 15 位會員，帳號密碼各至多 50 字元。修正跨帳號密碼誤登入、未回傳值、無效選項判斷、取消越界及額滿處理。 |
| 10.4 | 第一行最多 50 個非負 signed 64-bit 範圍整數，第二行目標值；依 `+` 優先列出所有運算式 | 使用 `void insertOp(...)`，只在 `main` 輸出。完成原本未完成題目，遵守乘法優先、序列不變，無解輸出 `not found`。 |

10.2 的山採用「嚴格上升後嚴格下降」，至少包含三個元素；平臺打斷山。講義未指定平臺、同長與無山情況：本實作同長取最先出現的一座，無山輸出 `0` 與空白第二行。

10.3 登入失敗訊息依範例畫面及原程式採用 `The username and the password don't match.`；講義文字另有 `This account doesn't exist.` 的不一致。各功能之間保留一個空白行。帳號資料僅存在程式記憶體。

10.4 用「已完成的加總 + 目前乘積」維持優先序，對超過目標的乘積使用飽和值；後續乘零仍可歸零，避免錯誤剪枝及整數溢位。顯式 DFS 堆疊每次交回一個答案給 `main`，不累積全部解。列舉最多有 `2^(n-1)` 個結果，50 個數字時若答案非常多，執行時間與輸出量本來就可能極大。

例如：

```text
輸入：
1 2 3
6
輸出：
[1 + 2 + 3], [1 * 2 * 3]
```

在 repo 根目錄執行 `python tests/test_labs_10_14.py`；可用 `--cxx` 指定編譯器。測試涵蓋 64-bit 邊界、50 個元素、山的獨立參考算法、運算式暴力枚舉比較、超大乘積後乘零及會員/座位回歸流程。
