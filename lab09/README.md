# Lab 9：Vector 與字串

依據課程 2021 年 Lab 9 講義與 Review，參考提供的原始程式資料夾中的 Lab 9.1–9.4 程式修正。未使用網路程式碼或函式庫排序／大小寫轉換函式。

每題是獨立 C++11 程式，從 repo 根目錄編譯，例如：

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic lab09/lab9_1.cpp -o lab9_1
./lab9_1
```

Windows 執行 `lab9_1.exe`；換檔名編譯其餘題目。

| 程式 | 使用方式 | 主要修正與要求 |
| --- | --- | --- |

| `lab9_2.cpp` | 輸入正筆數及對應整數，輸出遞增順序與整數中位數 | 使用 `vector`，自行撰寫 O(n log n) 合併排序，未呼叫現成排序函式。修正原版固定 100 格、未用 vector、不合法筆數、大數相加溢位。偶數筆的負數平均採向下取整，例如 -2、-1 的中位數為 -2。 |
