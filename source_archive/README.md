# 原始程式與本地資料保存

此區保存提供的 421 份非編譯程式、資料與設定：324 份 `.cpp`、1 份未正常命名的 C++、1 份 `main.cpp.temp` 草稿、51 份 TXT、43 份 Code::Blocks 設定與 1 份資料 ZIP。來源作者、學號及資料夾使用隨機名稱，真實對照只留在私有紀錄；資料夾分組也不代表已確認的程式作者。

[來源清單](source-manifest.json)逐檔列出原內容 SHA、保存內容 SHA、匿名變動與保存類型。各來源資料夾的相對結構與小資料仍可查看；原先已匿名處理的會員資料與 ZIP 沿用同一份匿名內容，保留紀錄數、欄位與 ZIP member 結構。13 份歷史 TXT 輸出照樣保存，屬於程式的本地觀察結果，不能當作教授提供的正確答案。

這些原始提交與草稿未在此區修復，也未宣稱符合題目。它們不加入預設 CMake build 或正式解答測試。43 份原專案設定中，27 份曾引用未提供的 `main.cpp` 等來源，清單明確記錄這些既有缺口；不另造檔案代替。要練習或重現正式解答，請先使用根目錄說明的 `lab*`、`2024` 或 `exams` 入口。

75 份 `.exe`、70 份 object、41 份 `.layout`、29 份 `.depend` 和 7 份使用 `.1`／`.3`／`.4` 副檔名的 MZ 執行檔屬於編譯結果或 IDE 暫存，未上傳。`.temp` 與未正常命名的 `.cpp` 經檔案內容確認是文字草稿，因此保留。

作業說明依課程年份、作業與文件種類只保留最新版本；舊程式、錯誤版本與歷史資料仍保留。抵免測驗資料依使用者要求排除，一般期中／期末課堂考試仍保留。原始文件及圖片由 [original_document_archive](../original_document_archive/README.txt)另行列管，並明確記錄因版本政策或使用者要求而未發布的文件。

執行 `python tools/check_source_archive.py` 可檢查清單、SHA、原程式非字串 token、匿名檔名、ZIP member 及已知原設定缺口。這是保存完整性的檢查，並非原程式功能通過測試。持有原資料夾時，可加 `--source-root` 比較全部原程式／小資料的 SHA 多重集合，偵測新增或尚未列管的非編譯資料。
