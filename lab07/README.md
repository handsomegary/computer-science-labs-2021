# Lab 7：遞迴

依據課程 2021 年 Lab 7 講義、`LAB7_2_smaple.cpp`、`LAB7_3_sample.cpp` 範本，參考提供的原始程式資料夾的 Lab 7.1–7.3 程式修正及補完。原 7.2 無法編譯，已補完排序與合併。

每題獨立編譯，從 repo 根目錄執行，例如：

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic lab07/lab7_1.cpp -o lab7_1
./lab7_1
```

Windows 執行 `lab7_1.exe`；替換檔名即可執行另外兩題。

| 程式 | 輸入／行為 | 符合的課程限制與修正 |
| --- | --- | --- |
| `lab7_1.cpp` | 輸入 0–2⁶³−1 整數，根號截斷至小數第十位；非法輸入重試 | 不使用標準函式庫根號函式。以十進位開平方長除法，每組兩位數呼叫一次自身，運算全用字串整數，能避免原版浮點比較過早終止／不終止，及大數無法保留十位小數的問題。0 顯示為 `0.0000000000`。 |
| `lab7_2.cpp` | 兩個由 1–9 組成的正整數序列，各自遞增排序後遞減合併 | 使用範本概念的拆分、插入排序、合併函式。全程遞迴，沒有 `for`、`while`、`do` 迴圈。合併直接逐位輸出，因此合併結果超出整數範圍仍正確。依題目假設，輸入沒有 0 且不超出 2⁶³−1。 |
| `lab7_3.cpp` | 選項 1 加、2 減、3 列出所有正因數、4 結束 | 保留範本兩個全域計數器與 `main` 兩個區域變數；`add`、`sub` 不新增區域變數，函式回傳型態維持 `void`。傳參考，操作後各自把次數加一，算術溢位時回報錯誤。非正數顯示 `No factorization`；正因數遞增、逗號分隔，1 不重複。非法選項、文字、EOF 不會卡住。 |

7.1 的結果等同 `floor(sqrt(n × 10²⁰))` 拆成整數部分與十位小數，所有合法輸入都使用相同精度。7.3 的因數枚舉只掃到根號附近，時間 O(√n)，避免原版掃描至 n。

執行 `python tests/test_labs_6_9.py` 驗證。7.1 用 Python 整數平方根獨立比對 2⁶³−1、完全平方數及固定亂數案例；7.2 驗證重複數字、18 位輸入與超過整數範圍的合併；7.3 驗證計數、1 的因數、負數與錯誤選項。
