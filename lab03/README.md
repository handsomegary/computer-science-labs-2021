# 2021 Lab 3：流程控制

根據 2021 Lab 3 講義與提供的原始作業修訂。僅保留正式 Lab 3.1–3.3，原資料夾內額外的二進位加法、十進位轉二進位實驗不是這份講義的題目。

| 檔案 | 題目 | 作法與範圍 |
| --- | --- | --- |
| `lab3_1.cpp` | 三個整數由小到大排序 | 三次比較與交換，不使用排序函式；支援 `int` 的最小及最大值。 |
| `lab3_2.cpp` | 階乘 | 用迴圈實際計算 0 到 20 的階乘，`0! = 1`；未硬編碼答案。 |
| `lab3_3.cpp` | 二進位轉十進位 | 讀入最多 19 位的二進位數值，用 `% 10`、`/ 10` 與整數權重逐位計算。 |

在此目錄編譯與執行，例如：

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic lab3_1.cpp -o lab3_1
./lab3_1
```

其餘題目替換檔名即可。Windows 執行 `./lab3_1.exe`。排序輸入 `12 56 -4`，結果 `-4->12->56`；階乘輸入 `7`，結果 `5040`；二進位輸入 `1101`，結果 `13`。

修正原作六個分支重複且同值不輸出問題；保留題目原本「三個不同整數」要求，同時讓同值輸入也有合理結果。階乘拒絕範圍外輸入，避免溢位。二進位轉換移除不必要的浮點 `pow` 與未使用變數，檢查非二進位數字與超出 19 位的數值；前導零不影響結果。不合法輸入會回傳非零狀態並在標準錯誤輸出說明。

測試包含六種排列、整數邊界、0–20 全部階乘、講義二進位範例、19 個 `1`（結果 `524287`）、錯誤數字及負值。
