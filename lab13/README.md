# Lab 13：Bits, Characters, C Strings and Structs

以 2021-12-30 **2015 update** 版講義為準，基於提供的原始程式修正。四個 `.cpp` 均可獨立編譯、提交：

```sh
g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic lab13_1.cpp -o lab13_1
```

其他題依序改成 `lab13_2`、`lab13_3`、`lab13_4`。Windows 執行 `.exe`；Linux/macOS 使用 `./lab13_1`。

| 題目 | 輸入與功能 | 題目限制與修正 |
| --- | --- | --- |
| 13.1 | 第一行 `The invoice lottery number is 12345678.`；第二行 1–10 張八位數發票，以空白分隔 | 以字串保留前導零，從末位逐位比對，取每張的最高獎項。修正陣列缺 NUL、`strtok` 空指標、只處理三張與未重設比對索引。 |
| 13.2 | 兩行父母基因，各為 `AA`、`Ai`、`BB`、`Bi`、`AB`、`ii` 等兩字元組合 | 保留範本 `bloodtype`、`MOM`、`DAD`、`child`、`input1`、`input2` 和 `calculate`；僅增加迴圈索引。修正範本未指定大小的陣列為 3 字元；只在 `main` 輸出。 |
| 13.3 | 劇院新增註冊電話、檔案電話欄位與選項 8 修改密碼/電話 | 5 登入或登出、6 名單、7 載入、8 修改、9 離開。修改前須同帳號密碼通過驗證。修正跨會員驗證、總是改到最後一個會員的索引錯誤與 EOF 假帳號。 |
| 13.4 | 多筆 `n d r`，接著 `n` 條早上路線、`n` 條晚上路線，`0 0 0` 結束 | 使用指定 `struct driver { int distance; int fine; };` 儲存每天距離及加班費。修正原始 50 人陣列卻允許 100 人的越界。 |

13.1 尾數符合 3、4、5、6、7、8 位分別得 200、1000、4000、10000、40000、200000 元；逐張列出獎項後輸出十進位總額，無獎使用講義訊息。

13.2 遍歷四種等機率子代組合，每種加 `0.25`；`i` 為隱性，`A` 與 `B` 同時存在為 `AB`。範例 `Ai` / `BB` 結果為 A:0、B:0.5、O:0、AB:0.5。

13.3 使用本目錄虛構帳號 `3_1.txt`，格式為 `Name Password Phone` 標題與三欄資料。電話用字串儲存保留前導零；依題目，電話不另外驗證。會員上限 15 位，帳號密碼上限 50 字元，所有資料只存於程式記憶體。修改密碼後舊密碼立即失效。

13.4 的 `1 ≤ n ≤ 100`、`1 ≤ d ≤ 10000`、`1 ≤ r ≤ 5`，路線長度至多 10000。將早上路線升序、晚上路線降序，短配長可以最小化超過 `d` 的總距離；時間複雜度 `O(n log n)`。

repo 根目錄執行 `python tests/test_labs_10_14.py`。測試涵蓋十張發票及所有獎項、81 組父母基因、密碼與電話修改後的正確帳號、100 位司機，以及小規模路線的所有排列比較。
