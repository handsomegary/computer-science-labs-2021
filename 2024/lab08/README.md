糖果題的圖片沒有給 `main`，故**總數在前、三位數在後**及純數值輸出是明訂參考介面。總數 0 回傳一個空路徑；三位數含 0 會造成原提示不停止，故回報 `error`。路徑數採 64 位元無號整數，只有最後所需結果溢位才回報 `error`；不會把無關中間狀態溢位誤報成答案錯誤。時間與記憶體均 O(糖果總數)。

評分題從圖片還原的規則：

- 單一數字得 0；`12` 得 1。
- 可切開的平衡段相加，例如 `1212` 得 2。
- `1…2` 包住內部分數後乘 5，例如 `1122` 得 5、`111222` 得 25。
- 依提示的特例，內部全部為 1 時得 1，例如 `1112`。
- 前面的孤立 2／其他數字分成零分段；沒有配對的尾端數字逐位縮短。例如 `212` 得 1、`1213` 得 1、`132` 得 0。

這些特例忠實反映 Review 程式碼；尚缺原題面對非 1／2 數字、未配對輸入及輸出提示的文字定義。組合數採精確整數，但極大 m、n 的結果位數與運算時間仍受實體資源限制。
