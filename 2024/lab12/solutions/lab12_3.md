# Lab 12.3：Booking System II（P113043，重建版）

本題依 2024 Lab 11.3 和 Lab 12.3 的流程圖與 `not_available` 圖碼重建。以下補齊全部互動規格，不宣稱是原 OJ 題面的逐字內容。

## 題目

建立飯店搜尋、訂房及依姓名查詢帳單的系統。這一版每個房號在每一天只有一間可訂：一旦同日同房號已被任何人預訂，就不能再訂。不同日期的庫存互相獨立。

搜尋只列出人數恰好相符且當天尚未被訂走的房型；一家飯店若沒有這種可顯示房型，連飯店標題也不印出。訂房成功會同步加入訂單與庫存紀錄；付款查詢只顯示帳單，不取消訂房或釋放庫存。

固定資料如下，每筆預訂只收一次列示房費：

| 房號 | 飯店 | 房型 | 人數 | 房費 NTD | 距離 |
| --- | --- | --- | --- | --- | --- |
| 1-1 | Cloud Hotel | Double | 2 | 1650 | 0.6km |
| 1-2 | Cloud Hotel | Quad | 4 | 3200 | 0.6km |
| 2-1 | Garden Hotel | Single | 1 | 760 | 1km |
| 2-2 | Garden Hotel | Double | 2 | 1380 | 1km |
| 2-3 | Garden Hotel | Twin | 2 | 1420 | 1km |
| 3-1 | City Big Hotel | Double | 2 | 2540 | 1.5km |
| 3-2 | City Big Hotel | Triple | 3 | 3670 | 1.5km |
| 3-3 | City Big Hotel | Quad | 4 | 4300 | 1.5km |

必須以函式分工，並使用 `vector<vector<string>> not_available` 保存每筆已占用的「日期、房號」配對。

## 輸入與互動流程

每輪印出以下主選單，最後 `>>> ` 不換行，再讀一個命令 token：

```text
1. Search System
2. Reserve System
3. Payment
exit(). Quit
>>> 
```

`exit()`、`exit`、`0` 直接結束，不印告別訊息。其他命令先在 `>>> ` 後印換行。未知命令印 `Unknown command` 和一個空白行，再回主選單。

命令 1：印 `Enter date: ` 讀日期，印 `How many people? ` 讀人數 1–4，列出符合人數的可訂房型。只有部分房型可訂時，只印那些資料列；沒有任何符合的可訂房型時，印 `No available rooms.`。

命令 2：依序印 `Enter your name: `、`Enter date: `、`Enter room number to reserve: `，讀姓名、日期、房號。房號錯誤時印 `Wrong number, please enter again!`；同日已被訂走時印 `The selected room is not available, please enter again!`。兩種情況都保留本次姓名和日期，只重新提示及讀房號。成功印 `Reserved successfully!`，加一筆訂單並占用該日房號。

命令 3：印 `Enter your name: `，讀完整姓名，顯示該姓名所有訂單及總額。姓名大小寫敏感、完全相符；名字相同視為同一位顧客，不另設帳號或密碼。

姓名單獨一行，長度 1–50 個可列印 ASCII 字元，可含中間空白，不含前後空白。日期為不含空白的 `M/D` token；月份 1–12、日為 1 到當月最大值，二月可有 29 天，沒有年份。前導零正規化，因此 `09/06` 與 `9/6` 會占用相同庫存。

日期錯誤時印 `Wrong date, please enter again!`，接著 `Enter date: ` 重讀。人數不在 1–4 或不是完整整數時印 `Invalid number of people, please enter again!`，接著 `How many people? ` 重讀。各提示不換行，各錯誤訊息換行。

重建版至多 1000 個主選單命令和 1000 筆成功預訂。訂房子流程沒有取消命令，會持續要求合法且可訂的房號；有效互動資料會提供可完成的選擇。任何輸入點遇到 EOF 時，保留已印內容後結束。

## 輸出格式

stdout 不包含使用者輸入回音，所以不換行的連續提示會出現在同一行。

搜尋在人數提示後換行。飯店標題為 `*** `、左對齊寬 20 的飯店名稱、`Distance: 距離 ***`。表頭依序為左對齊寬 4 的 `No.`、寬 35 的 `Room`、`Price`；資料列依序為寬 4 房號、寬 35 房型、`NTD ` 及右對齊至少寬 4 的房費。飯店之間和搜尋結束各空一行。

成功訂房訊息後空一行。有帳單時先換行，印 `*** This is 姓名's order ***`；每筆依建立順序印 `Date: M/D`、左對齊寬 35 的 `Hotel` 加 `Price`、45 個 `-`、寬 35 的「飯店名稱 房型 Room」加 `NTD ` 與至少寬 4 的房費，並空一行。最後印 45 個 `-`、寬 35 的 `Total` 加 `NTD ` 與至少寬 4 的總額，並空一行。

沒有該姓名訂單時印 `You have not reserved any rooms.` 並空一行。功能結束後回到主選單，最後退出時 stdout 仍停在已印出的 `>>> `，沒有換行。

## 解法

訂單保存姓名、正規化日期及房型索引。占用表每筆是 `{date,number}`。判斷可訂性時，同時比對日期與房號，不能只查其中一個欄位。

以下是本 repo 修正版核心，對應講義的 `not_available` 判斷；查到重複配對就拒絕：

```cpp
for (size_t i = 0; i < not_available.size(); ++i)
    if (not_available[i][0] == date && not_available[i][1] == number)
        return false;
return true;
```

搜尋先過濾人數與可訂性，直到遇到一家飯店第一個可印房型時才印標題，故不會留下空飯店。

每次可訂性查詢為 `O(B)`，搜尋最多八房型，即 `O(8B)`；帳單為 `O(B)`，記錄空間為 `O(B)`。`B` 是目前成功訂單數。

## 講義規則與補定規則

講義明示承接 Lab 11.3、同日每房型只有一間、以二維 vector 記錄占用、已訂拒絕及搜尋隱藏空飯店，也提供已占用/錯誤房號/成功字串。重建版補定完整首頁、日期正規化、姓名輸入、各項資料限制、無房/無帳單訊息、EOF 和退出別名，並明定查詢帳單不釋放庫存。

```cpp
// 2024 Lab 12.3 / P113043: independent hotel booking system.
#include <iomanip>
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

struct Room {
    string number, hotel, type, distance;
    int people, price;
};
struct Reservation { string name, date; int room; };
const Room rooms[8] = {
    {"1-1", "Cloud Hotel", "Double", "0.6km", 2, 1650},
    {"1-2", "Cloud Hotel", "Quad", "0.6km", 4, 3200},
    {"2-1", "Garden Hotel", "Single", "1km", 1, 760},
    {"2-2", "Garden Hotel", "Double", "1km", 2, 1380},
    {"2-3", "Garden Hotel", "Twin", "1km", 2, 1420},
    {"3-1", "City Big Hotel", "Double", "1.5km", 2, 2540},
    {"3-2", "City Big Hotel", "Triple", "1.5km", 3, 3670},
    {"3-3", "City Big Hotel", "Quad", "1.5km", 4, 4300}
};
const bool limited_rooms = true;

int Rooms(const string& number) {
    for (int i = 0; i < 8; ++i) if (rooms[i].number == number) return i;
    return -1;
}
bool is_available(const vector<vector<string> >& not_available, const string& date, const string& number) {
    if (!limited_rooms) return true;
    for (size_t i = 0; i < not_available.size(); ++i)
        if (not_available[i][0] == date && not_available[i][1] == number) return false;
    return true;
}
bool read_date(string& date) {
    string token;
    const int days[12] = {31,29,31,30,31,30,31,31,30,31,30,31};
    while (cin >> token) {
        istringstream parser(token);
        int month, day;
        char slash, extra;
        if (parser >> month >> slash >> day && !(parser >> extra) && slash == '/' &&
            month >= 1 && month <= 12 && day >= 1 && day <= days[month - 1]) {
            date = to_string(month) + '/' + to_string(day);
            return true;
        }
        cout << "Wrong date, please enter again!\nEnter date: ";
    }
    return false;
}
bool read_people(int& people) {
    string token;
    while (cin >> token) {
        istringstream parser(token);
        char extra;
        if (parser >> people && !(parser >> extra) && people >= 1 && people <= 4) return true;
        cout << "Invalid number of people, please enter again!\nHow many people? ";
    }
    return false;
}
void Search_System(const vector<vector<string> >& not_available) {
    string date;
    int people;
    cout << "Enter date: ";
    if (!read_date(date)) return;
    cout << "How many people? ";
    if (!read_people(people)) return;
    cout << '\n';
    string currentHotel;
    bool any = false;
    for (int i = 0; i < 8; ++i) {
        if (rooms[i].people != people || !is_available(not_available, date, rooms[i].number)) continue;
        if (currentHotel != rooms[i].hotel) {
            if (any) cout << '\n';
            currentHotel = rooms[i].hotel;
            cout << "*** " << left << setw(20) << currentHotel
                 << "Distance: " << rooms[i].distance << " ***\n"
                 << left << setw(4) << "No." << setw(35) << "Room" << "Price\n";
        }
        cout << left << setw(4) << rooms[i].number << setw(35) << rooms[i].type
             << "NTD " << right << setw(4) << rooms[i].price << '\n';
        any = true;
    }
    if (!any) cout << "No available rooms.\n";
    cout << '\n';
}
void Reserve_System(vector<Reservation>& reservations, vector<vector<string> >& not_available) {
    Reservation booking;
    cout << "Enter your name: ";
    if (!getline(cin >> ws, booking.name)) return;
    cout << "Enter date: ";
    if (!read_date(booking.date)) return;
    string number;
    while (true) {
        cout << "Enter room number to reserve: ";
        if (!(cin >> number)) return;
        booking.room = Rooms(number);
        if (booking.room == -1) { cout << "Wrong number, please enter again!\n"; continue; }
        if (!is_available(not_available, booking.date, number)) {
            cout << "The selected room is not available, please enter again!\n";
            continue;
        }
        if (limited_rooms) {
            vector<string> entry;
            entry.push_back(booking.date);
            entry.push_back(number);
            not_available.push_back(entry);
        }
        reservations.push_back(booking);
        cout << "Reserved successfully!\n\n";
        return;
    }
}
void Payment(const vector<Reservation>& reservations) {
    string name;
    cout << "Enter your name: ";
    if (!getline(cin >> ws, name)) return;
    bool found = false;
    long long total = 0;
    for (size_t i = 0; i < reservations.size(); ++i) {
        const Reservation& booking = reservations[i];
        if (booking.name != name) continue;
        if (!found) cout << "\n*** This is " << name << "'s order ***\n";
        found = true;
        const Room& room = rooms[booking.room];
        cout << "Date: " << booking.date << '\n'
             << left << setw(35) << "Hotel" << "Price\n"
             << "---------------------------------------------\n"
             << left << setw(35) << room.hotel + ' ' + room.type + " Room"
             << "NTD " << right << setw(4) << room.price << "\n\n";
        total += room.price;
    }
    if (!found) cout << "You have not reserved any rooms.\n\n";
    else cout << "---------------------------------------------\n"
              << left << setw(35) << "Total" << "NTD " << right << setw(4) << total << "\n\n";
}
int main() {
    vector<Reservation> reservations;
    // Lab 12.3's prescribed date/room table; disabled for the unlimited Lab 11.3.
    vector<vector<string> > not_available;
    string command;
    while (true) {
        cout << "1. Search System\n2. Reserve System\n3. Payment\nexit(). Quit\n>>> ";
        if (!(cin >> command)) return 0;
        if (command == "exit()" || command == "exit" || command == "0") return 0;
        cout << '\n';
        if (command == "1") Search_System(not_available);
        else if (command == "2") Reserve_System(reservations, not_available);
        else if (command == "3") Payment(reservations);
        else cout << "Unknown command\n\n";
        if (!cin) return 0;
    }
}
```
