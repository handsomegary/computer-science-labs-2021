# Lab 12.2：Digital Root（P113042，重建版）

本題依 2024 講義的 digit-sum 流程與 main 圖碼重建，並明確解決圖片和文字中的指標/參照型別衝突。

## 題目

一個非負整數的 digital root 是反覆把十進位各位數相加，直到結果只剩一位數。例如 12345 先得到 15，再得到 6。

撰寫 `void digitalRoot(int num, int *dRoot)`：把 `num` 的各位數之和累加到指標所指變數。`main` 每次呼叫前把 dRoot 設為 0，呼叫後把 num 換成 dRoot，只要結果至少為 10，就繼續呼叫。最終結果只能在 `main` 輸出，`main` 的自訂運算函式只允許呼叫 `digitalRoot`。

本重建版同時定義負數的結果：忽略負號，求其絕對數值的 digital root；0 的結果是 0。

## 輸入與限制

一個 signed 32-bit 整數，範圍 `[-2147483648,2147483647]`。

若使用完整官方模板，只能修改 `// CODE BEGIN` 到 `// CODE END` 的指定區塊。本 repo 的可編譯重建版保留該區塊標記。

## 輸出

只印 `digital root: X` 並換行，X 為 0–9 的結果。沒有輸入提示或中間加總輸出。

## 解法

`num % 10` 取得最後一位的有號餘數，取該位餘數的絕對值加到 `*dRoot`，再用 `num /= 10` 移除最後一位。這樣不需要對整個 `INT_MIN` 呼叫 abs，也不會因無法表示其正值而溢位。

以下是本 repo 修正版核心；它將講義圖片的各位數加總改為文字明訂的 pointer，並補上負數安全處理：

```cpp
void digitalRoot(int num, int *dRoot) {
    // CODE BEGIN
    while (num != 0) {
        const int digit = num % 10;
        *dRoot += digit < 0 ? -digit : digit;
        num /= 10;
    }
    // CODE END
}
```

第一次最多十位數，之後結果至多是兩位數，會快速縮小。總時間與十進位位數成正比，空間 `O(1)`。

## 講義規則與補定規則

講義第 5 頁明訂 `int *dRoot`，第 7 頁圖片卻使用 `int &dRoot`；本版依明訂文字採指標。圖片中的 main 重複加總與 `digital root:` 輸出被保留。提供資料未含完整原始 `.cpp` 模板，因此完整解答按圖碼還原。重建版補定 signed 32-bit 的全部範圍、負號處理與 0 的結果。

## 完整解答程式

<!-- SOLUTION_CODE_BEGIN -->
```cpp
// 2024 Lab 12.2 / P113042: explicit pointer prototype from the written requirement.
#include <iostream>
using namespace std;
void digitalRoot(int num, int *dRoot) {
    // CODE BEGIN
    // Sum absolute digit remainders; unlike abs(num), this also handles INT_MIN.
    while (num != 0) {
        const int digit = num % 10;
        *dRoot += digit < 0 ? -digit : digit;
        num /= 10;
    }
    // CODE END
}
int main() {
    int num, dRoot;
    if (!(cin >> num)) return 0;
    do {
        dRoot = 0;
        digitalRoot(num, &dRoot);
        num = dRoot;
    } while (dRoot >= 10);
    cout << "digital root: " << dRoot << '\n';
    return 0;
}
```
