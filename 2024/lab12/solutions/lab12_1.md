# Lab 12.1：Reverse Output of an Array（P113041，重建版）

本題依 2024 講義的五元素陣列與指標存取圖片重建，精確輸入輸出格式由本版補定。

## 題目

讀入五個整數，按相反順序輸出。資料必須存於五元素陣列，並傳入輸出函式；程式中每次存取陣列元素都必須使用指標算術及解參考，不使用索引運算子存取元素。

## 輸入與限制

剛好五個 signed 32-bit 整數，每個位於 `[-2^31,2^31-1]`。數字可以用空白或換行分隔。

## 輸出

輸出這五個整數的倒序，以一個空白分隔，行末換行，不印輸入提示，不留尾端空白。

## 範例

<!-- SAMPLES_BEGIN -->
以下輸出是程式的標準輸出，包含提示；不包含終端機回顯的使用者輸入。

### 範例 1 輸入

```text
1 2 3 4 5
```

### 範例 1 輸出

```text
5 4 3 2 1
```
<!-- SAMPLES_END -->

最先輸入的 1 最後輸出；最後輸入的 5 最先輸出。

## 解法

讀入第 `i` 個數值時使用 `*(numbers + i)`。將陣列傳入函式後，從偏移量 4 讀到 0 即為倒序。以下核心對應講義的指標算術圖片，分隔方式改為本版沒有尾端空白的輸出：

```cpp
for (int i = 4; i >= 0; --i) {
    if (i < 4) cout << ' ';
    cout << *(numbers + i);
}
cout << '\n';
```

陣列宣告的 `[5]` 是大小，不是元素存取，因此不違反使用指標的要求。時間及空間都是 `O(5)`，即固定常數。

## 講義規則與補定規則

講義明示讀五個整數、存入/傳遞陣列、所有元素存取使用 pointer，以及 4 到 0 的輸出迴圈。重建版補定 signed 32-bit 範圍、無提示和沒有尾端空白。未完整讀到五個整數時不呼叫輸出函式，直接結束；有效測資保證五個整數完整。

## 完整解答程式

<!-- SOLUTION_CODE_BEGIN -->
```cpp
// 2024 Lab 12.1 / P113041: store and access the five-element array via pointers.
#include <iostream>
using namespace std;
void reverse_output(const int *numbers) {
    for (int i = 4; i >= 0; --i) {
        if (i < 4) cout << ' ';
        cout << *(numbers + i);
    }
    cout << '\n';
}
int main() {
    int numbers[5];
    for (int i = 0; i < 5; ++i) if (!(cin >> *(numbers + i))) return 0;
    reverse_output(numbers);
}
```
