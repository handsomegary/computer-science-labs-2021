# Lab 11.1：Price Discount（P113037，重建版）

2024 投影片將此題誤標為 Lab 1.1；本重建版依所在週次編號為 Lab 11.1。題目按圖片中的價格、指標與折扣運算補齊，不是教授原題的逐字轉錄。

## 題目

輸入商品原價 `price` 及折扣倍率 `discount`，計算 `price × discount`，並用兩位小數輸出。必須宣告一個指向原價的指標，藉由指標存取價格。

例如 85 折應輸入 `0.85`，不是 `85`。倍率 0 表示免費，倍率 1 表示原價。

## 輸入與限制

依序輸入兩個有限實數，之間可以用空白或換行分隔。重建版規模為 `0 ≤ price ≤ 10^9`、`0 ≤ discount ≤ 1`；原價至多兩位小數、倍率至多四位小數。

計算採 C++ `double`；輸出採 `fixed << setprecision(2)` 格式化其乘積，不使用無條件捨去。評測以這個浮點及格式化行為為準。

## 輸出

在讀原價前印出 `Please enter the price: `，在讀倍率前印出 `Please enter the discount: `。兩個提示都含尾端空白且**沒有換行**。

最後印出 `After discount, the price is X.XX` 並換行，其中 `X.XX` 是折扣後價格，整數結果也必須補兩位小數。標準輸出不包含使用者輸入的回音，因此重導輸入時三段文字會在同一行。

原價 100、倍率 0.85 的乘積是 85，顯示為 `85.00`。

## 解法

先讓 `pricePtr` 指向 `price`，再經由解參考直接修改該變數。以下是本 repo 修正版核心；圖片中的 `pricePtr = &price` 與 `price = price * discount` 被整理為等價的指標存取：

```cpp
pricePtr = &price;
*pricePtr *= discount;
cout << fixed << setprecision(2)
     << "After discount, the price is " << *pricePtr << '\n';
```

時間及空間均為 `O(1)`。

## 講義規則與補定規則

講義明示 pointer、原價乘折扣、小數第二位，以及 discount 與結果提示片段。重建版補定原價提示、倍率有效範圍、資料精度與浮點格式化規則。原始完整 `.cpp` 範本未包含在提供資料中，完整解答依圖片中的核心語句還原。

## 完整解答程式

<!-- SOLUTION_CODE_BEGIN -->
```cpp
// 2024 Lab 11.1 / P113037 (mislabelled Lab 1.1 in the supplied slides).
#include <iomanip>
#include <iostream>
using namespace std;
int main() {
    double price, discount;
    double *pricePtr = 0;
    cout << "Please enter the price: ";
    if (!(cin >> price)) return 0;
    cout << "Please enter the discount: ";
    if (!(cin >> discount)) return 0;
    // CODE BEGIN
    pricePtr = &price;
    *pricePtr *= discount;
    // CODE END
    cout << fixed << setprecision(2) << "After discount, the price is " << *pricePtr << '\n';
}
```
