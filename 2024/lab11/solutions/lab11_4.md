# Lab 11.4：Apple and Banana（P113040，重建版）

本題依 2024 講義的猜數字規則、陣列比較與次數表重建，提示和勝負文字由本版補定。

## 題目

先設定一個長度為 `length`、各位數不重複的秘密數字，再由玩家連續猜測。秘密數字與猜測都是字元序列，前導零有效。

每次合法猜測得到兩個提示：Apple（A）是數字與位置都正確的位數，Banana（B）是數字存在於秘密數字中，但位置不對的位數。每一個秘密數字位置最多只能與猜測的一位配對，不能因猜測重複數字而多算 B。

若在次數上限內得到 `length` A、0 B，立刻獲勝。最後一次機會也可以獲勝；用完所有次數仍未猜中則失敗。

## 輸入與限制

先輸入整數 `length`，再輸入秘密數字，接著每個猜測是一個不含空白的 token。

合法長度是 3–8；次數限制依講義：

| 長度 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- |
| 最多合法猜測次數 | 4 | 7 | 11 | 16 | 22 | 29 |

秘密數字必須恰好有 `length` 個 ASCII 數字，且不能重複。猜測也必須恰好有 `length` 個數字，但本重建版**允許猜測重複數字**。例如猜測 `0000` 不是格式錯誤；配對計數仍不能把同一秘密位數重複使用。

有效測資至多提供 1000 個猜測 token；遊戲結束後剩餘輸入不再讀取。

## 輸出

不印輸入提示。每次合法猜測印 `xAyB` 並換行，其中 x、y 為 A、B 數量。若猜中，接著印 `You win!` 並換行，立即結束；若耗盡次數，印 `You lose!` 並換行。

長度不合法時只印 `Invalid length.` 並結束。秘密數字不合法時只印 `Invalid secret number.` 並結束。猜測格式不合法時印 `Invalid guess, please enter again.`，重新讀取猜測，**不耗猜測次數**。上述訊息皆換行。若提前遇到 EOF，直接結束，不另外宣告勝負。

## 解法

先找出位置相同的數字計入 A。其餘位置把秘密數字及猜測的 0–9 頻率分開計算，每個數字配對數為兩邊頻率的較小值；加總即為 B。

以下是本 repo 修正版核心。講義圖片比較未配對位數，本版用頻率陣列使重複猜測也有明確且不多算的結果：

```cpp
for (int i = 0; i < length; ++i) {
    if (secret[i] == guess[i]) ++*apple;
    else {
        ++secret_count[secret[i] - '0'];
        ++guess_count[guess[i] - '0'];
    }
}
for (int digit = 0; digit < 10; ++digit)
    *banana += secret_count[digit] < guess_count[digit]
             ? secret_count[digit] : guess_count[digit];
```

只有猜測通過格式檢查後才遞增 attempt。每次計算 `O(length + 10)`、額外空間 `O(10)`；本題長度有固定上限。

## 講義規則與補定規則

講義明示秘密數字不重複、A/B 定義、陣列與六組長度次數上限。重建版補定前導零、猜測可重複與單次配對、invalid guess 不計次、`xAyB` 格式、勝負文字、錯誤訊息與 EOF 行為。

## 完整解答程式

<!-- SOLUTION_CODE_BEGIN -->
```cpp
// 2024 Lab 11.4 / P113040: Apple and Banana, including leading-zero secrets.
#include <iostream>
#include <string>
using namespace std;

bool valid_digits(const string& number, int length, bool unique) {
    if (number.size() != static_cast<size_t>(length)) return false;
    bool seen[10] = {};
    for (int i = 0; i < length; ++i) {
        if (number[i] < '0' || number[i] > '9') return false;
        const int digit = number[i] - '0';
        if (unique && seen[digit]) return false;
        seen[digit] = true;
    }
    return true;
}
void score(const char *secret, const char *guess, int length, int *apple, int *banana) {
    int secret_count[10] = {}, guess_count[10] = {};
    *apple = *banana = 0;
    for (int i = 0; i < length; ++i) {
        if (secret[i] == guess[i]) ++*apple;
        else { ++secret_count[secret[i] - '0']; ++guess_count[guess[i] - '0']; }
    }
    for (int digit = 0; digit < 10; ++digit)
        *banana += secret_count[digit] < guess_count[digit] ? secret_count[digit] : guess_count[digit];
}
int main() {
    int length;
    if (!(cin >> length)) return 0;
    if (length < 3 || length > 8) { cout << "Invalid length.\n"; return 0; }
    const int limits[6] = {4,7,11,16,22,29};
    string input;
    if (!(cin >> input)) return 0;
    if (!valid_digits(input, length, true)) { cout << "Invalid secret number.\n"; return 0; }
    char secret[8], guess[8];
    for (int i = 0; i < length; ++i) secret[i] = input[i];
    for (int attempt = 0; attempt < limits[length - 3];) {
        if (!(cin >> input)) return 0;
        if (!valid_digits(input, length, false)) { cout << "Invalid guess, please enter again.\n"; continue; }
        for (int i = 0; i < length; ++i) guess[i] = input[i];
        int apple, banana;
        score(secret, guess, length, &apple, &banana);
        ++attempt;
        cout << apple << 'A' << banana << "B\n";
        if (apple == length) { cout << "You win!\n"; return 0; }
    }
    cout << "You lose!\n";
}
```
