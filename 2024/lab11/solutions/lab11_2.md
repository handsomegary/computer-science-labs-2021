# Lab 11.2：Date（P113038，重建版）

本題依 2024 講義的日期拆解與閏年程式碼圖片重建，並補定日期格式錯誤與年份範圍。

## 題目

給定一個不含空白的日期字串，判斷它是否是公曆中的合法日期。正常格式為八個 ASCII 數字 `YYYYMMDD`：前四位為年，接著兩位為月，最後兩位為日。

使用陣列儲存日期字元及各位數，將它們轉成整數年月日，再依月份及閏年規則判斷。

## 輸入與限制

輸入一個長度 1–100 的非空 token。可能包含非數字字元、可能不是八位，這些情況一律判定不合法。

合法日期的年份須為 1–9999、月份須為 1–12，日須至少是 1 且不超過當月天數。補零的 `00010101` 表示公元 1 年 1 月 1 日；`00000101` 不合法。

公曆閏年為：年份能被 400 整除，或能被 4 整除但不能被 100 整除。平年二月 28 天、閏年二月 29 天；4、6、9、11 月 30 天，其餘月份 31 天。

## 輸出

合法只印 `This is legal.`，否則只印 `This is not legal.`，行末換行。沒有輸入提示。

2000 能被 400 整除，所以 2 月 29 日合法；1900 是 100 的倍數但不是 400 的倍數，所以同樣的月日不合法。

## 解法

先檢查長度與每一字元，再用 `digit = character - '0'` 轉成數字。組合出年月日後，調整二月天數並檢查日的上下界。

以下是本 repo 修正版核心，對應講義的年月日拆解與公曆閏年判斷：

```cpp
const int year = date_int[0] * 1000 + date_int[1] * 100
               + date_int[2] * 10 + date_int[3];
const int month = date_int[4] * 10 + date_int[5];
const int day = date_int[6] * 10 + date_int[7];
int days[12] = {31,28,31,30,31,30,31,31,30,31,30,31};
if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) days[1] = 29;
legal = year >= 1 && month >= 1 && month <= 12
     && day >= 1 && day <= days[month - 1];
```

`&&` 從左至右短路，月份不合法時不會存取 `days[month - 1]`，避免越界。日期檢查只需固定八位，時間及額外空間皆為 `O(1)`，輸入字串儲存為 `O(L)`。

## 講義規則與補定規則

講義明示八位年月日、字元轉數字、陣列與公曆閏年，並提供兩個輸出字串。重建版補定無提示、長度/非數字錯誤處理、年份必須至少為 1，以及一個 token 的讀入格式。

## 完整解答程式

<!-- SOLUTION_CODE_BEGIN -->
```cpp
// 2024 Lab 11.2 / P113038: Gregorian calendar date, stored as character/digit arrays.
#include <iostream>
#include <string>
using namespace std;
int main() {
    string input;
    if (!(cin >> input)) return 0;
    char date[8];
    int date_int[8];
    bool legal = input.size() == 8;
    for (int i = 0; i < 8 && legal; ++i) {
        date[i] = input[i];
        if (date[i] < '0' || date[i] > '9') legal = false;
        else date_int[i] = date[i] - '0';
    }
    if (legal) {
        const int year = date_int[0] * 1000 + date_int[1] * 100 + date_int[2] * 10 + date_int[3];
        const int month = date_int[4] * 10 + date_int[5];
        const int day = date_int[6] * 10 + date_int[7];
        int days[12] = {31,28,31,30,31,30,31,31,30,31,30,31};
        if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) days[1] = 29;
        legal = year >= 1 && month >= 1 && month <= 12 && day >= 1 && day <= days[month - 1];
    }
    cout << (legal ? "This is legal.\n" : "This is not legal.\n");
}
```
