區間加總的筆數與元素提示依圖片；筆數提示缺少完整來源，採 `Please enter the size of the array:`。元素接受 [-2³¹, 2³¹−1]，使用 64 位元整數存十分位；總和超出 64 位元時明確回報錯誤，不會溢位。起迄索引從 0 算起，且 start≤end<size。

LBP 講義第 17 張投影片的圖片被另一段輸出程式覆蓋，仍可讀到「左 bit 3、左下 bit 5、下 bit 6」。因此採一致的 **row-major** 鄰點位元配置，其餘五個位置與初始維度提示需原題面核對：

| bit 0：左上 | bit 1：上 | bit 2：右上 |
| --- | --- | --- |
| bit 3：左 | 中央像素 | bit 4：右 |
| bit 5：左下 | bit 6：下 | bit 7：右下 |

排列必須輸出 n! 行，時間至少 O(n×n!)；大型輸入的輸出量本身不可避免。陣列皆依所需大小配置，配置失敗回報錯誤。執行 `python tests/test_2024_labs_6_9.py` 驗證，涵蓋非法索引、十分位邊界與負數、全部 720 個六元素排列、等值 LBP，以及逐一亮起八個鄰點來核對位元順序。
