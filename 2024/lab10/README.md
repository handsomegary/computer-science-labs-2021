# 2024 Lab 10：Vector

這一組依 **2024Fall_EE1007_CSLab_Lab10_20241204.pdf** 的 2024 題目獨立實作，和 2021 Lab 10 是不同題目。每個 `.cpp` 可單獨編譯、提交，不依賴其他原始檔。

```sh
g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic lab10_1.cpp -o lab10_1
```

其他題改成 `lab10_2`、`lab10_3`、`lab10_4`。Linux/macOS 執行 `./lab10_1`，Windows 執行對應 `.exe`。

提供的 PDF 是複習投影片，沒有完整 OJ 輸入輸出範例。下表列出本實作採用的確定格式；算法及講義有指定的文字、資料結構均依講義。

| 程式 / 題號 | 輸入 | 輸出與實作 |
| --- | --- | --- |
| `lab10_1.cpp` / P113033 Modifying Score | 學生人數 `n`，接著 `n` 個 0–100 整數分數，最後一個座號 `k` | 用 `std::vector<int>` 儲存分數，座號為 1 起算。選中分數加 10，最高 100；輸出整個修改後序列。座號越界只輸出講義的 `invalid student number.`。 |
| `lab10_2.cpp` / P113034 Transpose Matrix | `n m`，接著 `n×m` 個整數，按列輸入；兩維皆為 1–100 | 用 100×100 二維陣列與巢狀迴圈轉置，輸出 `m` 列、每列 `n` 個數，以單一空白分隔。 |
| `lab10_3.cpp` / P113035 Book Arrangement | 書本數 `n`，接著 `n` 行書名，可含空白 | 用講義允許的 `vector<vector<char>>` 儲存書名；依忽略 ASCII 英文字母大小寫的字典序排序，每行輸出一本。保留原字母大小寫；大小寫以外相同的書名保持輸入順序。 |
| `lab10_4.cpp` / P113036 Decrypting Message | 第一行 Caesar 加密訊息，第二行未加密的關鍵字或片語 | 搜尋使關鍵字出現在訊息中的 Caesar key，第一行輸出 1–26 的 key，第二行輸出整段解密訊息。英文大小寫分別循環，其他字元保留。 |

投影片未指定 10.1 的完整讀入方式及要印單一分數或全序列，本實作採用 `n`、`n` 個分數、`k` 與全序列輸出。10.3 未指定大小寫相同書名的次序，因此使用穩定排序。10.4 未指定無解或多解的處理，本實作無解輸出 `not found`；多解按照 key 1–26 依序選第一個可匹配的 key。訊息不需移動時，依講義輸出 **26**，不輸出 0。

10.1 範例：

```text
輸入：
4
0 90 91 100
3
輸出：
0 90 100 100
```

10.4 範例：

```text
輸入：
dwwdfn dw gdzq!
attack
輸出：
3
attack at dawn!
```
