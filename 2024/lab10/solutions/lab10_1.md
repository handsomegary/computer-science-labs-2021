# Lab 10.1：Modifying Score（P113033，重建版）

本題依 2024 講義的流程與 `modifyScore` 虛擬碼重建；以下補定規則是這份題目的一部分，不是教授原題的逐字轉錄。

## 題目

班上有 `n` 位學生，座號依序是 1 到 `n`。給定所有人的分數與一個座號 `k`，替該學生加 10 分，但調整後不能超過 100 分。其他學生的分數不變。若 `k` 不是班上的座號，輸出指定錯誤訊息。

必須使用 `std::vector<int>` 儲存分數；請用一個修改分數的函式處理座號檢查與調整。

## 輸入

依序輸入整數 `n`、`n` 個分數及整數 `k`。數字之間可以用空白或換行分隔。即使 `n = 0`，仍須輸入 `k`。

重建版有效資料限制為 `0 ≤ n ≤ 1000`，每個分數是 0–100 整數，`k` 可為任意 signed 32-bit 整數，因此可能小於 1 或大於 `n`。

## 輸出

若 `1 ≤ k ≤ n`，輸出全部 `n` 個調整後的分數，以一個空白分隔，行末換行，沒有多餘尾端空白。

否則只輸出 `invalid student number.` 並換行。空班級沒有合法座號。不印輸入提示，也不重印輸入資料。

## 解法

座號採 1 起算，但 vector 的索引採 0 起算，所以應操作 `scores[k - 1]`。先檢查上下界再存取，避免負數轉成無號索引或超出容器範圍。

分數不超過 90 時加 10，否則直接設為 100。以下是本 repo 修正版核心，對應講義的虛擬碼：

```cpp
bool modifyScore(vector<int>& scores, int k) {
    if (k <= 0 || static_cast<size_t>(k) > scores.size()) return false;
    scores[k - 1] = scores[k - 1] <= 90 ? scores[k - 1] + 10 : 100;
    return true;
}
```

修改本身為 `O(1)`；讀入及輸出全部分數為 `O(n)`，空間為 `O(n)`。

## 講義規則與補定規則

講義明示使用 vector、座號 `0 < k ≤ size`、加 10 封頂 100，以及錯誤字串。重建版補定人數先輸入、座號最後輸入、輸出完整序列、人數上限 1000 和空班級行為。上述限制內的完整輸入構成評測資料；不完整或無法讀取的整數輸入不在有效資料範圍內。

```cpp
// 2024 Lab 10.1 / P113033: Modifying Score.
#include <iostream>
#include <vector>
using namespace std;

bool modifyScore(vector<int>& scores, int k) {
    if (k <= 0 || static_cast<size_t>(k) > scores.size()) return false;
    scores[k - 1] = scores[k - 1] <= 90 ? scores[k - 1] + 10 : 100;
    return true;
}
int main() {
    int n, k;
    if (!(cin >> n) || n < 0) return 0;
    vector<int> scores(n);
    for (int i = 0; i < n; ++i) if (!(cin >> scores[i])) return 0;
    if (!(cin >> k)) return 0;
    if (!modifyScore(scores, k)) { cout << "invalid student number.\n"; return 0; }
    for (int i = 0; i < n; ++i) {
        if (i) cout << ' ';
        cout << scores[i];
    }
    cout << '\n';
}
```
