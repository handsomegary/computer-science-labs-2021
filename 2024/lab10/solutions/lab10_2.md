# Lab 10.2：Transpose Matrix（P113034，重建版）

本題依 2024 講義的二維陣列轉置範例重建，輸入輸出細節由本版補定。

## 題目

給定一個 `n` 列、`m` 欄的整數矩陣，將矩陣轉置成 `m` 列、`n` 欄。原矩陣第 `i` 列第 `j` 欄的元素，要成為結果第 `j` 列第 `i` 欄的元素。

請宣告足以容納 100×100 矩陣的二維陣列，以巢狀迴圈及一個轉置函式完成，不可以只在輸出時改變讀取順序而省略結果矩陣。

## 輸入與限制

先輸入 `n m`，再依列由左至右輸入 `n×m` 個整數。數字之間可用任意空白分隔。

`1 ≤ n,m ≤ 100`。本重建版允許每個元素位於 signed 64-bit 範圍 `[-2^63, 2^63-1]`，因此解答以 `long long` 儲存；轉置不會對數值做加減乘除。

## 輸出

輸出轉置結果的 `m` 列，每列 `n` 個整數，以一個空白分隔，每列行末換行，沒有尾端空白。沒有輸入提示。

## 解法

以下迴圈結構直接對應講義圖片的 `result[j][i] = matrix[i][j]`，數值型別改成重建版允許的 `long long`：

```cpp
void transpose(const long long matrix[][100], long long result[][100], int n, int m) {
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j)
            result[j][i] = matrix[i][j];
}
```

二維陣列作為函式參數時，第二維必須明確宣告為 100，讓編譯器知道每列的跨度。轉置與輸出皆為 `O(nm)`。實作配置兩個固定 100×100 陣列；實際資料量為 `O(nm)`。

## 講義規則與補定規則

講義明示 100×100 容量、二維陣列/向量、巢狀迴圈與轉置函式示例。重建版補定先輸入維度、逐列輸入、每列空白格式及 signed 64-bit 元素範圍。維度不在 1–100 或資料讀取失敗時，現有程式直接結束且不輸出；這類輸入不列入有效測資。

## 完整解答程式

```cpp
// 2024 Lab 10.2 / P113034: Transpose Matrix.
#include <iostream>
using namespace std;

void transpose(const long long matrix[][100], long long result[][100], int n, int m) {
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j) result[j][i] = matrix[i][j];
}
int main() {
    int n, m;
    if (!(cin >> n >> m) || n < 1 || n > 100 || m < 1 || m > 100) return 0;
    long long matrix[100][100], result[100][100];
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j) if (!(cin >> matrix[i][j])) return 0;
    transpose(matrix, result, n, m);
    for (int i = 0; i < m; ++i) {
        for (int j = 0; j < n; ++j) {
            if (j) cout << ' ';
            cout << result[i][j];
        }
        cout << '\n';
    }
}
```
