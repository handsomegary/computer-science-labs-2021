# Lab 10.3：Book Arrangement（P113035，重建版）

本題依 2024 講義對字典序、忽略大小寫及書名儲存的提示重建。它是完整的重建規格，不是原 OJ 題面的逐字抄錄。

## 題目

輸入若干本書的書名，把它們依「忽略英文字母大小寫的字典序」由小到大排列，輸出時保留各書名原本的大小寫、空白和標點。

比較時僅把 ASCII `A`–`Z` 視為 `a`–`z`；其他字元以其 ASCII 數值比較。若所有共同位置的字元都相同，較短的書名排在前面。若兩本書忽略大小寫後完全相同，維持原本輸入順序。

## 輸入與限制

第一行是一個整數 `n`，接著有剛好 `n` 行書名。書名可以是空行，也可以包含空白，不能用 `cin >> title` 只讀一個單字。

本重建版規模為 `0 ≤ n ≤ 1000`；每個書名至多 1000 個可列印 ASCII 字元，即 `0x20`–`0x7E`。前後空白都是書名的一部分。換行只用來分隔書名；若檔案使用 CRLF，行末的 `\r` 不屬於書名。

使用二維陣列或講義允許的二維 vector 儲存書名。解答採 `vector<vector<char>>`，不限制成固定 99 字元書名。

## 輸出

依排列後順序，每行輸出一本完整書名。所有非換行字元保留。`n = 0` 時沒有輸出。沒有輸入提示或書名編號。

## 解法

先用 `getline` 取得完整書名，再轉存到二維 vector。比較器逐字比較摺成小寫的 ASCII 值。以下是本 repo 修正版核心，實現講義的 case-insensitive comparison：

```cpp
unsigned char folded(unsigned char letter) {
    return letter >= 'A' && letter <= 'Z'
        ? static_cast<unsigned char>(letter + ('a' - 'A')) : letter;
}
bool title_less(const vector<char>& left, const vector<char>& right) {
    size_t i = 0;
    while (i < left.size() && i < right.size()) {
        const unsigned char a = folded(static_cast<unsigned char>(left[i]));
        const unsigned char b = folded(static_cast<unsigned char>(right[i]));
        if (a != b) return a < b;
        ++i;
    }
    return left.size() < right.size();
}
```

接著做插入排序：只有當新書名**嚴格小於**前一本時才右移，因此相等書名不會交換，排序是穩定的。若最長書名長度為 `L`，最壞時間為 `O(n²L)`，儲存空間為 `O(nL)`。

## 講義規則與補定規則

講義明示儲存書名、字典序、忽略大小寫、可任選排序法，也列出二維 vector 作為資料結構。重建版補定逐行輸入、可包含空白/空書名、ASCII 範圍、規模上限、相同書名採穩定順序與每行一書的輸出格式。

## 完整解答程式

```cpp
// 2024 Lab 10.3 / P113035: Book Arrangement; stable ASCII case-insensitive order.
#include <iostream>
#include <limits>
#include <string>
#include <vector>
using namespace std;

unsigned char folded(unsigned char letter) {
    return letter >= 'A' && letter <= 'Z' ? static_cast<unsigned char>(letter + ('a' - 'A')) : letter;
}
bool title_less(const vector<char>& left, const vector<char>& right) {
    size_t i = 0;
    while (i < left.size() && i < right.size()) {
        const unsigned char a = folded(static_cast<unsigned char>(left[i]));
        const unsigned char b = folded(static_cast<unsigned char>(right[i]));
        if (a != b) return a < b;
        ++i;
    }
    return left.size() < right.size();
}
int main() {
    int n;
    if (!(cin >> n) || n < 0) return 0;
    cin.ignore(numeric_limits<streamsize>::max(), '\n');
    vector<vector<char> > titles(n);
    string line;
    for (int i = 0; i < n; ++i) {
        if (!getline(cin, line)) return 0;
        if (!line.empty() && line.back() == '\r') line.pop_back();
        titles[i].assign(line.begin(), line.end());
    }
    // Stable insertion sort keeps the original order of titles equal ignoring case.
    for (int i = 1; i < n; ++i) {
        vector<char> current = titles[i];
        int j = i;
        while (j > 0 && title_less(current, titles[j - 1])) {
            titles[j] = titles[j - 1];
            --j;
        }
        titles[j] = current;
    }
    for (int i = 0; i < n; ++i) {
        for (size_t j = 0; j < titles[i].size(); ++j) cout << titles[i][j];
        cout << '\n';
    }
}
```
