# Lab 10.4：Decrypting Message（P113036，重建版）

本題依 2024 講義的 Caesar 位移搜尋流程重建；多解、無解與字元處理均在下列規格補定。

## 題目

一段訊息以 Caesar cipher 加密：每個小寫英文字母在 `a`–`z` 中向後循環位移 `key` 格，大寫字母在 `A`–`Z` 中各自循環位移；其餘字元完全不變。

你知道原訊息中曾出現一段關鍵字/片語。找出使「加密後的關鍵字」成為已知密文之連續子字串的 key，再用該 key 解密整段密文。合法 key 為 1–26；key 26 表示英文字母不變，必須輸出 26 而不是 0。

若有多個 key 可匹配，選**數值最小的合法 key**。同一 key 有多處匹配不影響結果。不要求單字邊界，也不忽略字母大小寫。

## 輸入與限制

第一行是密文，第二行是未加密的關鍵字/片語。兩行都可含空白和標點；重建版每行至多 2000 個可列印 ASCII 字元。空密文或空關鍵字也有定義，見下方輸出規則。

CRLF 的行末 `\r` 視為換行的一部分，前後其他空白保留。必須儲存訊息與關鍵字的字元序列；解答採 vector 字元陣列。

## 輸出

若找到匹配，第一行輸出 key，第二行輸出完整解密訊息，兩行皆換行。若關鍵字為空、比密文長，或不存在任何 key 可匹配，只輸出 `not found` 並換行。

只有非字母的非空關鍵字也使用同一規則：若它本來就出現在密文，所有 key 都能匹配，故選 key 1，並用 1 解密整段訊息。

## 解法

依 key 1、2、…、26 的順序，掃描密文所有可能起點，逐字比較位移後的關鍵字。首次成功即可返回，這同時保證 key 最小。以下是本 repo 修正版核心；它對應講義「加密 keyword、檢查對應、解密 message」的流程：

```cpp
char shift_letter(char letter, int amount) {
    if (letter >= 'a' && letter <= 'z')
        return static_cast<char>('a' + (letter - 'a' + amount + 26) % 26);
    if (letter >= 'A' && letter <= 'Z')
        return static_cast<char>('A' + (letter - 'A' + amount + 26) % 26);
    return letter;
}
```

搜尋時 `amount = key`；解密時 `amount = -key`。本題的 amount 落在 -26–26，因此先加 26 可避免 C++ 負餘數影響。密文長度 `M`、關鍵字長度 `W` 時，最壞時間 `O(26MW)`，空間 `O(M+W)`。

## 講義規則與補定規則

講義明示 Caesar 密文與 keyword、搜尋 key 後解密，以及 key 在 1–26 且不變位移必須印 26。重建版補定兩行輸入、保留大小寫與非字母、連續子字串匹配、選最小 key、空字串/無解訊息和字元長度上限。

## 完整解答程式

<!-- SOLUTION_CODE_BEGIN -->
```cpp
// 2024 Lab 10.4 / P113036: find the Caesar key, then decrypt the complete message.
#include <iostream>
#include <string>
#include <vector>
using namespace std;

char shift_letter(char letter, int amount) {
    if (letter >= 'a' && letter <= 'z') return static_cast<char>('a' + (letter - 'a' + amount + 26) % 26);
    if (letter >= 'A' && letter <= 'Z') return static_cast<char>('A' + (letter - 'A' + amount + 26) % 26);
    return letter;
}
int find_key(const vector<char>& message, const vector<char>& keyword) {
    if (keyword.empty() || keyword.size() > message.size()) return 0;
    for (int key = 1; key <= 26; ++key) {
        for (size_t start = 0; start + keyword.size() <= message.size(); ++start) {
            size_t i = 0;
            while (i < keyword.size() && message[start + i] == shift_letter(keyword[i], key)) ++i;
            if (i == keyword.size()) return key;
        }
    }
    return 0;
}
int main() {
    string line, word;
    if (!getline(cin, line) || !getline(cin, word)) return 0;
    if (!line.empty() && line.back() == '\r') line.pop_back();
    if (!word.empty() && word.back() == '\r') word.pop_back();
    vector<char> message(line.begin(), line.end()), keyword(word.begin(), word.end());
    const int key = find_key(message, keyword);
    if (key == 0) { cout << "not found\n"; return 0; }
    cout << key << '\n';
    for (size_t i = 0; i < message.size(); ++i) cout << shift_letter(message[i], -key);
    cout << '\n';
}
```
